This is my platforming game that im working on for the Hackclub Terra Event.
This project was made using Blender, VS code, Unity, and Fl Studio.
You cannot build this project.
To play this project you can go to https://play.unity.com/en/games/75252d14-6d5a-4d3d-aa36-053b92379697/platmorfing-game
Future implementation may be made so this project can be downloaded and built seperately from the web
This project is also a big WIP, that means player movement mechanics, models, textures, and everything else may be subject to change.

Movement Controls:
WASD to move, Space to Jump, Esc to pasue and unpause game

Basic Mechanics:
Player can accelerate to a max speed of 200u
Player can cling to specific walls for 3 seconds and jump off specific walls

User settings:
- chage your name (press escape and click on the input field, type your name then press enter)
- pause, resume, quit, restart buttons
- level select button in pause menu

Things Im struggling with:
